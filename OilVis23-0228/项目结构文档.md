# OilVis23-0228 项目结构文档

## 📋 项目概述

**OilVis23-0228** 是一个成品油管道可视化监控系统，采用前后端分离架构，主要用于管道参数监控、预测分析、实时数据展示等功能。

### 🏗️ 技术栈
- **前端**: Vue.js 2.x + Element UI + ECharts + Vuex
- **后端**: Node.js + Express + MongoDB + Mongoose
- **数据库**: MongoDB
- **其他**: WebSocket、JWT认证、OPC数据采集

## 🌐 API接口说明

### 主要API端点

#### 1. **认证相关**
```
POST /Judge/login          # 用户登录
POST /Judge/check          # 验证码检查
```

#### 2. **实时数据**
```
GET /hpdg/realtime/latest           # 获取最新实时数据
GET /hpdg/realtime/recent?count=48  # 获取最近N条实时数据
```

#### 3. **预测数据**
```
GET /prediction/station/{stationName}/sequence?count=6    # 获取预测序列
GET /prediction/station/{stationName}/indexed/{index}    # 获取指定索引预测数据
GET /prediction/station/{stationName}/all               # 获取所有预测数据
```

#### 4. **管道信息**
```
GET /elevation/elevation-data       # 获取高程数据
GET /elevation/debug-data          # 调试数据库状态
```

#### 5. **参数监控**
```
GET /params/station/{stationName}   # 获取站点参数
GET /flow/data                     # 获取流量数据
```

## 🚦 启动流程

### 1. **后端启动**
```bash
cd server
npm install
npm run server
# 服务运行在 http://localhost:3000
```

### 2. **前端启动**
```bash
cd vue-client
npm install
npm run dev
# 服务运行在 http://localhost:9001
# 局域网访问: http://[IP]:9001
```

### 3. **数据库连接**
- MongoDB连接配置在 `server/database/db.js`
- 支持多数据库连接（管段信息、黄埔-东莞管段等）
- 智能降级：数据库无数据时自动使用模拟数据

## 🐛 常见问题

### 1. **跨域问题**
- 解决方案：使用webpack代理配置
- 配置文件：`vue-client/config/index.js`

### 2. **403权限错误**
- 解决方案：JWT令牌自动添加
- 相关文件：`src/main.js`, `middlewares/verifyToken.js`

### 3. **数据库连接失败**
- 解决方案：检查MongoDB服务状态
- 调试接口：`GET /elevation/debug-data`

### 4. **局域网访问问题**
- 解决方案：修改host为0.0.0.0，使用代理路径
- 配置文件：`vue-client/config/index.js`
