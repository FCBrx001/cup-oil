# 站点标签排序功能说明

## 🎯 功能概述

无论用户以什么顺序点击站点，标签都会按照固定的优先级顺序显示：

**优先级顺序：黄埔 > 十字窖 > 站点2 > 东莞**

## 📋 排序规则

### 优先级定义
```javascript
stationPriority: ['黄埔', '十字窖', '站点2', '东莞']
```

### 排序逻辑
- 标签显示顺序始终遵循优先级，而非点击顺序
- 图表对比时，站点1（左侧数据）为优先级更高的站点
- 站点2（右侧数据）为优先级较低的站点

## 🔄 使用场景示例

### 场景1：先点击东莞，后点击黄埔
**点击顺序**：东莞 → 黄埔
**标签显示**：[黄埔] [东莞]
**图表标题**：黄埔 vs 东莞

### 场景2：先点击站点2，后点击十字窖
**点击顺序**：站点2 → 十字窖
**标签显示**：[十字窖] [站点2]
**图表标题**：十字窖 vs 站点2

### 场景3：先点击东莞，后点击十字窖
**点击顺序**：东莞 → 十字窖
**标签显示**：[十字窖] [东莞]
**图表标题**：十字窖 vs 东莞

## 🎨 视觉效果

### 标签颜色
标签颜色基于显示位置（排序后的索引）而非点击顺序：
- 第一个标签：绿色 (success)
- 第二个标签：橙色 (warning)

### 图表颜色
图表中的颜色基于站点名称，保持一致性：
- 黄埔：橙红色系
- 十字窖：浅绿色系
- 站点2：金黄色系
- 东莞：青绿色系

## 🔧 技术实现

### 核心计算属性
```javascript
sortedSelectedValves() {
  if (!this.selectedValves || this.selectedValves.length === 0) {
    return [];
  }
  
  // 按照站点优先级排序
  return [...this.selectedValves].sort((a, b) => {
    const priorityA = this.stationPriority.indexOf(a.valveName);
    const priorityB = this.stationPriority.indexOf(b.valveName);
    
    // 如果站点不在优先级列表中，放到最后
    if (priorityA === -1) return 1;
    if (priorityB === -1) return -1;
    
    return priorityA - priorityB;
  });
}
```

### 模板更新
```vue
<!-- 使用排序后的站点数组 -->
<el-tag
  v-for="(valve, index) in sortedSelectedValves"
  :key="valve.valveName"
  size="small"
  :type="getTagType(index)"
  class="valve-tag"
>
  {{ valve.valveName }}
</el-tag>
```

## 🎯 用户体验优势

1. **一致性**：无论点击顺序如何，显示结果都一致
2. **可预测性**：用户可以预期标签的显示顺序
3. **逻辑性**：按照管线的物理顺序或重要性排序
4. **专业性**：体现了系统的专业性和规范性

## 📝 注意事项

1. **原始数据保持不变**：`selectedValves` 数组保持点击顺序，只有显示时进行排序
2. **响应式更新**：当站点选择变化时，排序会自动更新
3. **兼容性**：现有的功能逻辑保持不变，只是显示顺序改变
4. **扩展性**：可以轻松修改 `stationPriority` 数组来调整排序规则
