```javascript
// 核心配置
Vue.prototype.$axios = Axios;
Axios.defaults.baseURL = '/api';

// 全局拦截器
Axios.interceptors.request.use(config => {
  const excludeUrls = ['/Judge/login', '/Judge/check', '/hpdg/'];
  const needsToken = !excludeUrls.some(url => config.url.includes(url));
  
  if (needsToken) {
    const token = sessionStorage.getItem('token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
  }
  return config;
});
```

## 🔐 安全架构

### 1. **JWT认证机制**

#### 令牌生成 (`login_router.js`)
```javascript
const token = jwt.sign(
  { userId: user.id, username: user.username },
  secretKey,
  { expiresIn: '24h' }
);
```

#### 令牌验证 (`middlewares/verifyToken.js`)
```javascript
const verifyToken = (req, res, next) => {
  const token = req.headers.authorization?.split(' ')[1];
  
  if (!token) {
    return res.status(401).json({ message: '未提供访问令牌' });
  }
  
  jwt.verify(token, secretKey, (err, decoded) => {
    if (err) {
      return res.status(403).json({ message: '令牌无效' });
    }
    req.user = decoded;
    next();
  });
};
```

### 2. **权限控制**

#### 接口权限分级
- **公开接口**: 登录、验证码
- **认证接口**: 需要JWT令牌
- **管理接口**: 需要管理员权限

#### 前端权限控制
```javascript
// 路由守卫
router.beforeEach((to, from, next) => {
  const token = sessionStorage.getItem('token');
  if (to.meta.requiresAuth && !token) {
    next('/login');
  } else {
    next();
  }
});
```
