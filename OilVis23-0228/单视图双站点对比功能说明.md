# 单视图双站点对比功能说明

## 🎯 功能概述

重新设计的图表系统采用**单视图模式**，根据选择的站点数量自动切换显示模式：

- **单站点模式**：点击一个站点时，显示该站点的温度和压力数据
- **双站点对比模式**：点击两个站点时，显示两个站点的温度对比或压力对比

## 📊 显示模式

### 1. 单站点模式
当选择一个站点时：
- 显示该站点的温度和压力数据
- 可以通过按钮切换显示温度、压力或两者
- 实际数据用实线，预测数据用虚线

### 2. 双站点对比模式  
当选择两个站点时：
- 只显示一种数据类型的对比（温度或压力）
- 通过切换按钮选择显示温度对比或压力对比
- 不同站点用不同颜色区分

## 🎮 控制按钮

### 单站点模式按钮
- **温度按钮**：切换温度数据显示
- **压力按钮**：切换压力数据显示
- 至少保持一个按钮激活状态

### 双站点模式按钮
- **温度对比按钮**：显示两个站点的温度对比
- **压力对比按钮**：显示两个站点的压力对比
- 同时只能选择一种对比类型

## 🎨 颜色方案

### 站点颜色
- **黄埔站**: 橙红色系 (#FF6B35 实际, #FF8C42 预测)
- **东莞站**: 青绿色系 (#4ECDC4 实际, #45B7B8 预测)
- **十字窖**: 浅绿色系 (#A8E6CF 实际, #88D8A3 预测)
- **站点2**: 金黄色系 (#FFD93D 实际, #FFC312 预测)

### 线条样式
- **实际数据**: 实线
- **预测数据**: 虚线

## 🔧 技术实现

### 关键组件
```javascript
// 判断是否为双站点模式
isDualStationMode() {
  return this.selectedValves && this.selectedValves.length === 2;
}

// 双站点对比类型（temperature 或 pressure）
dualCompareType: 'temperature'
```

### 图表配置方法
- `getBaseChartOption()`: 单站点图表配置
- `getDualStationCompareOption()`: 双站点对比图表配置

### 按钮切换逻辑
- 单站点模式：`toggleTemperature()`, `togglePressure()`
- 双站点模式：`setDualCompareType(type)`

## 📱 用户交互流程

### 选择单个站点
1. 点击任意站点
2. 图表显示该站点的温度和压力数据
3. 可通过按钮切换显示内容

### 选择两个站点
1. 点击第一个站点
2. 点击第二个站点
3. 图表自动切换为对比模式
4. 默认显示温度对比
5. 可通过按钮切换为压力对比

### 重置选择
- 点击站点标签的关闭按钮可移除站点
- 当只剩一个站点时，自动切换回单站点模式

## 🎯 优势特点

1. **界面简洁**：只有一个图表区域，避免界面分割
2. **功能完整**：支持单站点详细分析和双站点对比
3. **操作直观**：按钮状态清晰反映当前显示模式
4. **性能优化**：统一的图表实例，减少资源消耗
5. **响应灵敏**：快速切换不同显示模式

## 🔍 调试信息

控制台输出包括：
- `🎯 单站点模式` - 显示当前站点名称
- `🎯 双站点对比模式` - 显示对比的两个站点和数据类型
- `🎯 双站点温度/压力对比` - 显示具体的对比配置

## 📝 使用建议

1. **单站点分析**：适合详细查看某个站点的完整数据
2. **双站点对比**：适合比较两个站点的同类型数据趋势
3. **快速切换**：通过按钮快速在不同视图间切换
4. **数据筛选**：根据分析需求选择合适的显示模式
