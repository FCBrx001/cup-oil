# 双站点对比图表问题修复说明

## 🔍 问题描述

1. **温度图表无数据显示**: 左侧温度对比图表空白，没有显示任何数据
2. **压力数据显示位置不当**: 右侧压力数据都挤在图表底部，无法清楚看到数据变化趋势
3. **Y轴范围不合理**: 固定的Y轴范围导致数据无法在图表中心合理显示

## 🛠️ 修复方案

### 1. 智能Y轴范围计算
- **动态计算数据范围**: 根据实际数据的最小值和最大值动态调整Y轴范围
- **数据类型适配**: 为温度和压力数据设置不同的默认范围
  - 温度默认范围: 15-35℃
  - 压力默认范围: 0-5MPa
- **智能边距**: 根据数据范围大小设置合理的显示边距

### 2. 数据范围计算优化
```javascript
calculateDataRange(dataArrays, dataType = 'unknown') {
  // 提取所有有效数据值
  // 根据数据类型设置默认范围
  // 智能计算边距，确保数据在中心显示
}
```

### 3. 颜色方案重新设计
- **黄埔站**: 橙红色系 (#FF6B35 实际, #FF8C42 预测)
- **东莞站**: 青绿色系 (#4ECDC4 实际, #45B7B8 预测)
- **实线/虚线区分**: 实际数据用实线，预测数据用虚线

### 4. 调试信息增强
- 添加数据检查日志，便于排查数据获取问题
- 显示每个站点的数据计数
- 记录Y轴范围计算过程

## 🎯 预期效果

修复后的双站点对比图表应该具备以下特性：

1. **左侧温度对比图**:
   - 显示黄埔站和东莞站的温度数据
   - 数据在Y轴中心区域显示
   - 使用不同颜色区分两个站点

2. **右侧压力对比图**:
   - 显示黄埔站和东莞站的压力数据  
   - 数据分布在合理的Y轴范围内
   - 清晰显示压力变化趋势

3. **自适应范围**:
   - Y轴范围根据实际数据动态调整
   - 确保数据在图表中心显示
   - 避免数据挤压在边缘

## 🔧 技术细节

### 数据结构检查
- 确保 `getCombinedStationData()` 返回正确的数据结构
- 验证温度和压力数据格式: `[time, value]`
- 检查数组长度和数据有效性

### Y轴配置
- 使用计算得出的 `min` 和 `max` 值
- 保留1位小数精度
- 最小值不小于0（压力数据）

### 调试方法
1. 打开浏览器开发者工具
2. 查看控制台输出的数据检查信息
3. 确认每个站点的数据计数
4. 验证Y轴范围计算结果

## 📝 使用说明

1. 选择黄埔站和东莞站
2. 左侧图表显示两站点温度对比
3. 右侧图表显示两站点压力对比
4. 数据应在图表中心合理显示
5. 不同站点使用不同颜色区分
